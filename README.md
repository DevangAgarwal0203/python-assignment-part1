# Python Assignment — Part 1: Python Basics & Control Flow

## Theme: Student Grade Tracker

A command-line Student Grade Tracker built using core Python concepts — loops, conditionals, string manipulation, and f-strings.

## Tasks

- **Task 1** — Data Parsing & Profile Cleaning (5 marks)
- **Task 2** — Marks Analysis using Loops & Conditionals (8 marks)
- **Task 3** — Class Performance Summary (7 marks)
- **Task 4** — String Manipulation Utility (5 marks)

## How to Run

```
python part1_grade_tracker.py
```

No external libraries needed — pure Python only.

> Task 2 has an interactive while loop that asks for subject names and marks. Type `done` to exit the loop.
